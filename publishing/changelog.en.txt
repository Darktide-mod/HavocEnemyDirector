3.0.0 — Configurable encounter director

- Add a library of independent formations with named members, count ranges and weighted variants.
- Add independent time, progress and condition-edge deployment rules, with windows, cooldowns, quotas, active limits, priorities, weights and waves.
- Add optional continuous condition checks after the first accepted member, while preserving start-only gating by default.
- Add rule-driven and adaptive Build / Pressure / Recovery modes, global admission limits and per-phase size/frequency controls.
- Add HCM-linked deployment multipliers and relative native field overrides alongside fixed values and inherited values.
- Separate roamer-layout and director seeds, with per-deployment timer, variant and member streams that do not reseed native randomness.
- Use paced native groups, patrol behavior, specialist slots and monster registration; retain native admission and shared HCM navigation checks.
- Bound encounter budgets, preserve composition proportions, rotate pending submissions fairly and expire unfulfilled requests.
- Reorganize the UI into Director, Formation library, Deployment rules, Native templates, and Presets & changes. Add readable categories, percent input, source/result readouts and a name editor; mark only selected dropdown options.
- Migrate native-editor presets to the expanded data format while retaining unsupported legacy generator files. Save formations, rules, settings and both seeds.
- Validate configuration, native method adapters, deterministic scheduling, migration, host authority, mission snapshots, UI callbacks and three-language layouts offline. This release does not include an in-game playtest or measured FPS claim.
- Requires Havoc Condition Manager 3.6.11 or newer. HCM 3.6.11 source remains unchanged.
- Contains no diagnostic subsystem. Install current companions and restart the game; remove the old HED installation folder before a manual upgrade.
