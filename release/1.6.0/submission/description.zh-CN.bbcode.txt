[size=5][b]浩劫高级敌人生成器[/b][/size]

浩劫高级敌人生成器以 SoloPlay 和浩劫词条管理器为前提，同时支持 Realms 联机会话。它在词条管理器中增加“高级”页，读取所选词条，将原版刷怪来源归类，生成下一局使用的可编辑配置。Realms 联机时以房主的刷怪配置为准。

[*]新增“删除所选”：弹窗显示完整模板名和文件名，确认后仅删除该文件；取消或Esc保留文件，已加载的配置不变。

[/list]

[size=4][b]玩家模板[/b][/size]

进入“高级生成器 → 模板库”，输入名称后点击“保存当前配置”。名称最多64个字符，支持中文，需符合Windows文件名规则。原生输入框支持输入和粘贴；回车或点击其他位置完成编辑，Esc取消编辑。完成编辑后仍需点击保存；同名文件需确认后才覆盖。

模板文件夹：%APPDATA%/Fatshark/Darktide/HavocEnemyDirector/templates

首次打开模板库时创建文件夹。“复制模板文件夹路径”可将地址复制后粘贴到资源管理器中打开。模板与安装目录分离，更新模组或通过Vortex重新部署不会替换已保存的模板。

[list]
[*]保存：将当前设置以指定名称写入JSON文件。
[*]加载：选择模板，查看摘要并确认。替换已保存的Director配置，以及模板中的词条、阵营、环境和倍率；下一局生效，进行中的任务继续使用本局快照。
[*]分享：直接发送保存的JSON文件，或选中模板后点击“复制分享内容”。
[*]导入：将收到的JSON文件放入专用文件夹后刷新，或选择“从剪贴板导入”，查看或修改名称后保存。保存导入文件不会自动应用，需要另行加载。
[*]删除：选择模板后点击“删除所选”，弹窗会显示完整模板名和文件名。只有点击“确认删除”才永久删除该文件；取消或Esc保留文件。当前已加载的配置不受影响，损坏的模板文件也可这样删除。
[/list]

模板保存自建及默认生成器的修改、已删除生成器、单位池和权重、禁用单位、容量以及投放开关。加载词条和倍率时统一更新，保留手动调整的生成器数值。任务与难度仍由玩家选择；比较原版默认数值时请使用相同任务和难度，部分生成器编号与难度有关。词条不可用或环境与所选任务不兼容时，会阻止加载并说明原因。

模板采用带版本号的JSON数据格式，不接受Lua脚本。每个文件最大256 KiB，文件夹最多256个JSON文件；文件读取仅在模板操作时执行。模板库在高级模式下可用，原版模式仍将高级控件置灰。Realms中的刷怪继续以房主加载的配置为准。

[size=4][b]生成器、池子与节奏[/b][/size]

可编辑周期、推进、环境驻敌及受支持的事件来源；弱化怪物保留独立处理。行为不同的来源分别归类，不会把所有词条强行压成同一种生成器。

[list]
[*]调整每批数量、间隔、推进距离和生成器上限。
[*]编辑单位权重、禁用单位，以及各类敌人与全局存活容量。
[*]新增自定义周期或推进生成器，暂停、删除或重置单个生成器。
[*]根据所选词条恢复完整的默认生成器组。
[/list]

修改词条会重建与组合效果对应的默认生成器配置。建议先选词条和倍率，再做自定义编辑。关卡内保存的修改在下一局配置快照中生效。

[size=4][b]单位池编辑[/b][/size]

通过单位池底部的“添加单位”选择符合限制的单位；空间不足时列表向上展开。新加入的单位权重为 1；单位名旁的 + 用于加入，× 用于从当前生成器移除。“全部”也显示权重为零的可选单位，“池内”仅显示已配置的成员。单独的“允许/禁止”控制全部高级生成器并保留权重；全局禁用的单位需先解除禁用，再从列表添加。

自定义生成器复用最小空缺编号：在 #1、#2、#3 中删除 #2 后，新建会使用 #2，其他生成器的编号与设置不变。

[size=4][b]倍率与容量[/b][/size]

默认总容量按所选敌人倍率中的最高值设置：1 倍 240、2 倍 330、3 倍 420、4 倍 510、5 倍 600。各类容量按对应倍率调整；1 倍默认值为普通敌人 120、精英 45、特感 16、Boss 4。这些数值是可编辑的上限，并不代表一定生成同样数量的敌人。

点击数字可直接输入或粘贴。回车或点击其他位置确认，Esc 取消。按住 + 或 − 约 400 毫秒后开始连续调整，后续每 80 毫秒执行一步。

每批数量、周期和推进距离独立编辑。修改数量不会再重算另外两项；倍率后的预览继续按照所选倍率和模式更新。

[size=4][b]额外投放开关[/b][/size]

“额外投放”默认开启。关闭后停止原版防速通、防分队、落单惩罚、热度追加特感和普通精英巡逻，也包括单人被扑倒后的原版追加投放。

词条生成器以及词条明确要求的原版巡逻仍遵循各自规则。任务和活动生成保留独立控制。开关在下一局生效，修改词条或恢复默认时不会被重置，也不会增加全场敌人扫描。

“场景触发”仅控制地图事件的批次刷怪、持续增援和事件特感。腐化装甲、仪式等词条效果继续按各自规则生效；保留指定任务角色和目标推进逻辑。开关下局生效，修改词条或恢复生成器默认时保留设置。

“双子伏击”为独立开关，默认开启，仅控制浩劫难度状况附带的伏击。开启时按原版概率与触发条件执行，关闭时禁止该伏击。不影响双子专属任务或手动加入自定义池的双子。设置下局生效，修改词条或恢复生成器默认时保留。

[size=4][b]依赖与安装[/b][/size]

需要 Darktide Mod Loader、Darktide Mod Framework、SoloPlay 和浩劫词条管理器。使用 Realms 联机时还需安装 Realms，SoloPlay 仍为前提。本版配套版本为 Solo Play 2.6.2、Havoc Condition Manager 2.4.9。

[size=4][b]Vortex 安装[/b][/size]

[list]
[*]退出游戏，在 Vortex 中管理 Darktide，并先安装上方列出的依赖，包括浩劫词条管理器。
[*]从本模组 Files 页面下载安装 ZIP，在 Vortex 中选择 Install From File（从文件安装）导入，然后启用模组并点击 Deploy Mods（部署模组）。
[*]打开 Load Order（加载顺序），启用相关条目并按 SoloPlay → HavocConditionManager → HavocEnemyDirector 排列，保留其他模组。
[*]启动游戏，从 Mod 选项打开浩劫词条管理器，通过侧边箭头进入“高级”页。
[/list]

[size=4][b]手动安装[/b][/size]

[list]
[*]退出游戏，并按各依赖的说明完成前置安装。
[*]打开 Darktide 游戏目录；Steam 中可通过“属性 → 已安装文件 → 浏览”进入。
[*]进入游戏的 mods 文件夹，将本 ZIP 内的 HavocEnemyDirector 文件夹解压到此处，确认最终路径为 mods/HavocEnemyDirector。
[*]编辑 mods/mod_load_order.txt，在 HavocConditionManager 后另起一行加入 HavocEnemyDirector；SoloPlay 必须位于两者之前。保留其他条目。
[*]保存文件并启动游戏，打开浩劫词条管理器的“高级”页。
[/list]

从 Mod 选项打开浩劫词条管理器，先选择词条和倍率，再通过侧边箭头进入“高级”页。支持英文、简体中文、繁体中文；更改游戏语言后重启。

[size=4][b]框架开关[/b][/size]

可在 Darktide Mod Framework 中启用或禁用本模组。大厅内立即生效；本地或 Realms 任务中切换时，会保存开关并在下一局应用，当前任务继续使用已初始化的词条和刷怪配置，并显示提示。已有设置会保留。

需要安装并启用 Havoc Condition Manager 2.4.7 或更新版本。关闭高级生成器后隐藏高级页，词条管理器仍可使用基础模式。

[size=4][b]已知问题与适用范围[/b][/size]

部分推进生成器的标识包含难度相关参数，因此删除后切换难度，可能再次出现。1.5.8 尚未修复这一问题。调整难度后应重新核对生成器列表，不应依赖本版严格限制为仅 Boss 任务。

高级生成器投放的特感使用游戏原版卡住与距离清理判定，每帧最多检查两个。原版注入、任务单位、Boss 和仪式单位由原有系统管理。本版不包含通用的敌人重部署。提高容量会增加 CPU 负担与帧耗时，5 倍时尤其明显；可降低容量或刷新频率。本模组支持 SoloPlay 和玩家主机的 Realms 任务，刷怪由房主控制，不承诺官方匹配支持。

已通过代码、词条规则和模拟界面检查，本版尚未新增实机测试。其他刷怪改造模组可能覆盖相同系统。
