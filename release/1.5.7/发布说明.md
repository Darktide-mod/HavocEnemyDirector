安装 ZIP 的最外层只有 HavocEnemyDirector/，不含其他模组或嵌套压缩包。

Vortex：管理 Darktide → Install From File 导入此 ZIP → 启用 → Deploy Mods → 调整 Load Order。

手动：将 ZIP 解压到 Darktide/mods，得到 mods/HavocEnemyDirector；在 mod_load_order.txt 中添加此模组名称。

必需依赖：Darktide Mod Loader、Darktide Mod Framework、Solo Play、Havoc Condition Manager

可选依赖：Realms — for player-hosted sessions

具体加载顺序见三语正文。PNG 单独上传 Images，文案复制到页面；只将 files 中的 ZIP 上传 Files。

高级生成器 1.5.7：删除后复用最小空缺编号；新增单位选择列表和池内添加、移除按钮。保留类别、阵营和词条替换限制，移除单位不改变其他生成器或全局禁用设置。配置在下一局应用。

此流程不会部署游戏文件或上传 Nexus。服务器扫描在实际上传后进行。
