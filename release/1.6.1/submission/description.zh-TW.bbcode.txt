[size=5][b]浩劫高階敵人生成器[/b][/size]

浩劫高階敵人生成器以 SoloPlay 和浩劫詞條管理器為前提，同時支援 Realms 聯機會話。它在詞條管理器中增加“高階”頁，讀取所選詞條，將原版刷怪來源歸類，生成下一局使用的可編輯配置。Realms 聯機時以房主的刷怪配置為準。

[size=4][b]玩家範本[/b][/size]

進入「高階生成器 → 範本庫」，輸入名稱後點擊「儲存目前設定」。名稱最多64個字元，支援中文，需符合Windows檔名規則。原生輸入框支援輸入及貼上；Enter或點擊其他位置完成編輯，Esc取消編輯。完成編輯後仍需點擊儲存；同名檔案需確認後才覆寫。

範本資料夾：%APPDATA%/Fatshark/Darktide/HavocEnemyDirector/templates

首次開啟範本庫時建立資料夾。「複製範本資料夾路徑」可將位址複製後貼至檔案總管中開啟。範本與安裝目錄分離，更新模組或透過Vortex重新部署不會取代已儲存的範本。

[list]
[*]儲存：將目前設定以指定名稱寫入JSON檔案。
[*]載入：選擇範本，查看摘要並確認。取代已儲存的Director設定，以及範本中的詞條、陣營、環境及倍率；下一局生效，進行中的任務繼續使用本局快照。
[*]分享：直接傳送儲存的JSON檔案，或選取範本後點擊「複製分享內容」。
[*]匯入：將收到的JSON檔案放入專用資料夾後重新整理，或選擇「從剪貼簿匯入」，查看或修改名稱後儲存。儲存匯入檔案不會自動套用，需要另行載入。
[*]刪除：選擇範本後點擊「刪除所選」，彈窗會顯示完整範本名稱及檔名。只有點擊「確認刪除」才永久刪除該檔案；取消或Esc保留檔案。目前已載入的設定不受影響，損壞的範本檔案也可這樣刪除。
[/list]

範本儲存自建及預設生成器的修改、已刪除生成器、單位池和權重、禁用單位、容量及投放開關。載入詞條和倍率時統一更新，保留手動調整的生成器數值。任務與難度仍由玩家選擇；比較原版預設數值時請使用相同任務及難度，部分生成器編號與難度有關。詞條無法使用或環境與所選任務不相容時，會阻止載入並說明原因。

範本採用帶版本號的JSON資料格式，不接受Lua指令碼。每個檔案最大256 KiB，資料夾最多256個JSON檔案；檔案讀取僅在範本操作時執行。範本庫在高階模式下可用，原版模式仍將高階控制項灰顯。Realms中的刷怪繼續以房主載入的設定為準。

[size=4][b]生成器、池子與節奏[/b][/size]

可編輯週期、推進、環境駐敵及受支援的事件來源；弱化怪物保留獨立處理。行為不同的來源分別歸類，不會把所有詞條強行壓成同一種生成器。

[list]
[*]調整每批數量、間隔、推進距離和生成器上限。
[*]編輯單位權重、禁用單位，以及各類敵人與全域存活容量。
[*]新增自訂週期或推進生成器，暫停、刪除或重置單個生成器。
[*]根據所選詞條恢復完整的預設生成器組。
[/list]

修改詞條會重建與組合效果對應的預設生成器配置。建議先選詞條和倍率，再做自訂編輯。關卡內儲存的修改在下一局配置快照中生效。

[size=4][b]單位池編輯[/b][/size]

透過單位池底部的「新增單位」選擇符合限制的單位；空間不足時清單向上展開。新加入的單位權重為 1；單位名旁的 + 用於加入，× 用於從目前生成器移除。「全部」也顯示權重為零的可選單位，「池內」僅顯示已設定的成員。獨立的「允許/禁止」控制全部高階生成器並保留權重；全域禁用的單位需先解除禁用，再從清單新增。

自訂生成器重用最小空缺編號：在 #1、#2、#3 中刪除 #2 後，新建會使用 #2，其他生成器的編號與設定不變。

[size=4][b]倍率與容量[/b][/size]

預設總容量按所選敵人倍率中的最高值設定：1 倍 240、2 倍 330、3 倍 420、4 倍 510、5 倍 600。各類容量按對應倍率調整；1 倍預設值為普通敵人 120、精英 45、特感 16、Boss 4。這些數值是可編輯的上限，並不代表一定生成同樣數量的敵人。

點選數字可直接輸入或貼上。回車或點選其他位置確認，Esc 取消。按住 + 或 − 約 400 毫秒後開始連續調整，後續每 80 毫秒執行一步。

每批數量、週期和推進距離獨立編輯。修改數量不會再重算另外兩項；倍率後的預覽繼續按照所選倍率和模式更新。

[size=4][b]額外投放開關[/b][/size]

“額外投放”預設開啟。關閉後停止原版防速通、防分隊、落單懲罰、熱度追加特感和普通精英巡邏，也包括單人被撲倒後的原版追加投放。

詞條生成器以及詞條明確要求的原版巡邏仍遵循各自規則。任務和活動生成保留獨立控制。開關在下一局生效，修改詞條或恢復預設時不會被重置，也不會增加全場敵人掃描。

「場景觸發」僅控制地圖事件的批次刷怪、持續增援和事件特感。腐化裝甲、儀式等詞條效果繼續按各自規則生效；保留指定任務角色和目標推進邏輯。開關下局生效，修改詞條或恢復生成器預設時保留設定。

「雙子伏擊」為獨立開關，預設開啟，僅控制浩劫難度狀況附帶的伏擊。開啟時按原版機率與觸發條件執行，關閉時禁止該伏擊。不影響雙子專屬任務或手動加入自訂池的雙子。設定下局生效，修改詞條或恢復生成器預設時保留。

[size=4][b]依賴與安裝[/b][/size]

需要 Darktide Mod Loader、Darktide Mod Framework、SoloPlay 和浩劫詞條管理器。使用 Realms 聯機時還需安裝 Realms，SoloPlay 仍為前提。本版配套版本為 Solo Play 2.6.2、Havoc Condition Manager 2.4.9。

[*]從本模組 Files 頁面下載安裝 ZIP，在 Vortex 中選擇 Install From File（從檔案安裝）匯入，然後啟用模組並點選 Deploy Mods（部署模組）。
[*]開啟 Load Order（載入順序），啟用相關條目並按 SoloPlay → HavocConditionManager → HavocEnemyDirector 排列，保留其他模組。

[size=4][b]框架開關[/b][/size]

可在 Darktide Mod Framework 中啟用或禁用本模組。大廳內立即生效；本地或 Realms 任務中切換時，會儲存開關並在下一局應用，當前任務繼續使用已初始化的詞條和刷怪配置，並顯示提示。已有設定會保留。

需要安裝並啟用 Havoc Condition Manager 2.4.7 或更新版本。關閉高階生成器後隱藏高階頁，詞條管理器仍可使用基礎模式。

[size=4][b]已知問題與適用範圍[/b][/size]

部分推進生成器的標識包含難度相關引數，因此刪除後切換難度，可能再次出現。1.5.8 尚未修復這一問題。調整難度後應重新核對生成器列表，不應依賴本版嚴格限制為僅 Boss 任務。

高階生成器投放的特感使用遊戲原版卡住與距離清理判定，每幀最多檢查兩個。原版注入、任務單位、Boss 和儀式單位由原有系統管理。本版不包含通用的敵人重新部署。提高容量會增加 CPU 負擔與幀耗時，5 倍時尤其明顯；可降低容量或刷新頻率。本模組支援 SoloPlay 和玩家主機的 Realms 任務，刷怪由房主控制，不承諾官方匹配支援。

已透過程式碼、詞條規則和模擬介面檢查，本版尚未新增實機測試。其他刷怪改造模組可能覆蓋相同系統。
