# 高级生成器编辑器开销优化

实际发现：每次滚动、展开菜单或切换筛选都会重新复制配置、收集原版词条生成源、编译全部生成器，并扫描和排序单位列表。窗口本身并非每帧重建，但这些浏览操作会反复触发相同的计算。

现在在窗口内缓存生成源、编译结果、单位替换函数与单位列表。缓存依赖配置对象及版本、保持顺序的词条列表、阵营、原版阻力／挑战等级、三个弱 Boss 池选项和显示语言。上述值变化即失效；关闭窗口后不跨窗口保存。倍率的实际显示仍即时计算。实际任务调度和原版生成源读取流程未改动。

检查：120 次滚动刷新，加上筛选与菜单操作，仅收集和编译一次；修改上限、阵营、词条及顺序、同一个难度管理器中的等级、弱 Boss 选项后重建；缓存的生成器、单位权重与直接重新编译逐项一致。完整回归还覆盖模板保存／导入／删除、数值输入与长按、原版模式、三种语言和 11 种分辨率。

模板目录仍在打开、手动刷新或文件操作时读取，以便识别玩家从外部添加的文件。此次未运行游戏测量实际开窗延迟或帧率，不能把浏览阶段调用次数减少等同于全局 FPS 提升。
