# 浩劫敌人导演

为 SoloPlay 和 Realms 建立具名编队，让不同投放规则拥有独立时机，并通过可选的自适应导演调节压力。HED 同时保留原版敌人模板精调，可以按需跟随 HCM 的整体倍率。

## DIY 词条与天赋联动

Havoc Condition Manager 的 DIY 词条和死灵 DIY 天赋可请求已有的具名编队或允许生成的敌人类型。请求进入导演原有的调度与刷怪流程，遵守当前容量、落点、阶段和节奏条件。请求成功表示已入队，不保证所有请求敌人都能生成。

部署编辑器与原生模板规则支持检查生效词条 ID 和具名信号。复制 ID 后点击条件数值粘贴。DIY 暂停动作可同时阻止 HED 接纳新刷怪任务与继续生成队列成员，完成、过期及任务清理会释放队列状态。单次请求、并发状态及全局请求次数均有限制，约束连续增援链。

docs/diy 包含接口说明、可编辑 JSON 示例与三语手册。对应联动需要当前 HCM 和死灵 DIY 版本；HCM 仍是 HED 的必要依赖。普通 DIY 敌人通过共用生成路径保留独立来源标记，特感与怪物保留各自原生注册流程。

## 开始使用

从模组选项打开 Havoc Enemy Director，或进入本地游戏设置的“详细调节”页。界面分为“导演总览”“编队库”“投放规则”“原版模板”“方案与变更”五个区域。

- 创建编队，选择敌人类别、成员兵种和人数范围。
- 建立调用该编队的投放规则，选择经过时间、向前推进或条件转为满足时触发。
- 设置首次到场时间、附加条件和整局额度，准备好后启用额外编队导演。

额外导演默认关闭，原版模板编辑可独立使用。设置自动保存，下一局生效；当前任务保留开局配置。

点击数字可输入或粘贴，回车或点击外部确认，Esc 取消；长按加减可连续调整。点击编队或规则名称即可重命名，最多 48 个字符。较长列表可滚动，下拉菜单只标记当前选中项。

## 编队库

最多保存 32 个编队与 64 条投放规则，同一类别可以建立多个独立编队，支持尸潮敌群、小股敌群、特感、怪物及巡逻编队。每个编队最多八个带权变体，每个变体最多十六种成员。一次遭遇抽取一个变体；成员的上下限表示人数，变体权重表示抽取倾向。

同一编队可被多条规则调用。复制编队或规则会建立独立对象，投放规则副本拥有独立随机流。仍被投放规则引用的编队不能直接删除，需要先移除对应规则。

每个变体在运行时缩放前最多配置 300 名普通敌人、16 名特感或 3 只怪物。怪物编队支持瘟疫欧格林、纳垢兽与混沌魔物；任务角色和剧情 Boss 不在此编队库中开放。

## 投放规则

每条规则独立保存首次到场时间、再次投放间隔、冷却、整局额度和同时活跃遭遇上限。多条规则调用同一编队，也不会共用这些计数。

- 时间触发：指定最短、最长间隔；再次投放的间隔从首名成员被接纳后开始计算。
- 推进触发：指定首次主路径距离及下一次所需继续推进距离；一次跨过多个门槛不会积压补发。
- 条件触发：条件由不满足变为满足时执行一次；持续满足不会反复触发，须先变为不满足才能重新触发。
- 可进一步设置有效时间窗口、一次遭遇的波数及波间等待。

每组最多八项条件，可要求全部满足或任意一项满足。条件包括有效玩家、战斗负担、原版节奏、怪物、任务事件、原版尸潮生成、协同状态和推进情况。默认只限制遭遇开始，也可选择在首名成员到场后继续检查，避免第一只怪物出现就使同编队的后续成员被自己的条件卡住。

整局额度统计至少已有一名成员被接纳的遭遇；0 表示该规则不限次数。等待生成和仍有存活成员的遭遇都会占用活跃额度。遭遇次数、成员人数及波数分别计算。

多条规则同时符合要求时，可以先比较优先级再按权重抽取，也可直接按权重抽取。高优先级可能让低优先级规则持续等待。要求某个 HED 阶段的规则需要自适应模式。

## 自适应压力与到场限制

规则模式按已配置规则运行。自适应模式经历蓄压、施压、恢复，各阶段具有独立时长范围、人数倍率及频率倍率。战斗负担过高或有效玩家过少时可提前进入恢复；恢复须同时达到规定时长与低负担条件才结束。阶段频率设为 0 会暂停 HED 的新增提交。

导演控制额外编队，原版节奏和任务脚本继续运行。全局设置控制两次接纳间隔、活跃遭遇上限、最低有效玩家数、战斗负担门槛，以及是否允许在任务事件期间额外投放。

普通成员分批使用原版生成与敌群管理；巡逻沿用原版巡逻行为，特感占用可用的原版槽位，怪物使用原版登记流程。普通敌人与怪物通过 HCM 检查出生距离、遮挡和实际可达性；特感沿用原版选点与保护机制，可能延后到场或被替换。

每次 HED 遭遇的所有波次合计最多 256 名普通敌人、16 名特感或 3 只怪物。缩放后超过额度时，按成员比例缩减；波数也受遭遇总额度限制。等待中的编队轮流提交，过期请求取消，不积压成连续补发。已被原版槽位接纳的特感继续执行原版流程。HED 自定义普通编队不进入 HCM 的自动回收补投池，以保留独立活跃额度；原版敌群仍使用 HCM 回收。

## HCM 联动与原版模板

投放规则可跟随 HCM 的人数和频率，再乘自己的倍率。普通尸潮、小股成员跟随对应人数控制，精英跟随“敌群精英人数”；特感跟随并行容量，怪物跟随遭遇数，巡逻普通成员从一倍开始。尸潮、小股潮、特感的再次间隔跟随对应频率，其他类别从一倍开始。首次时间、最短冷却及明确配置的波次仍使用本规则的数值。

原版模板包括战斗节奏与热度、驻军、尸潮、特感、怪物、自动事件、词条机制和受支持的任务战斗节点。依次选择来源、模式与分支，可切换常用参数、全部字段、已修改字段。抗性分档与挑战分档分别标注，不等同于浩劫等级。

数值字段可选择跟随 HCM、使用固定值，或在 HCM 结果上乘倍率。原版值、HCM 后的值和 HED 模板结果分别显示；概率按百分比输入，详情可展开原版标识。

原版遭遇条件默认追加到现有检查上，只有支持的协同尸潮条件列表允许替换。选择一个模板不会自动启用该刷怪来源。任务目标及不支持的函数字段继续由原版控制。旧的“同时活跃尸潮上限”字段已从常用参数中排除，因为核对的源码未确认其实际读取位置。

难度、已选词条及运行时修正仍可能影响模板效果。任务事件点数不是敌人人数；HCM 事件预算倍率还会作用于原版最终预算与封顶。

## 随机种子

导演种子与驻军布局种子分别提供「固定种子」开关。关闭时沿用任务种子，开启后可输入 1–2147483646 的整数，关闭会保留输入值。每条投放按稳定身份分别使用计时、变体、成员人数随机流，不重新设定游戏全局随机数。

相同种子与相同输入可复现 HED 的选择。玩家移动、原版随机、规则竞争和可用出生点仍会影响实际战斗。布局种子用于驻军布置，不负责选择任务地图，也不会统一所有原版系统的随机性。

## 方案

方案保存 HCM 数值、原版固定值与相对倍率、原版条件、编队、投放规则、导演设置、两类 HED 种子的开关与数值，以及 HCM 词条事件种子；缺少 HCM 种子的旧方案保留当前该项设置。任务、词条、阵营和环境选择仍由 SoloPlay 保存。

文件夹：%APPDATA%/Fatshark/Darktide/HavocEnemyDirector/templates

- 名称最多 64 个字符；覆盖已有文件需要确认。
- 选择文件、查看摘要，再加载为下一局配置。
- 分享 JSON 文件或复制分享内容。可从剪贴板导入，也可放入文件夹后刷新；导入不会自动加载。
- 删除文件需要确认，也不会重置当前已加载配置。

文件上限 256 KiB。上一版原版模板方案会迁移，无法兼容的早期生成器方案仍留在磁盘上。无效字段和不适配的成员会被拒绝；方案只保存数据，不执行 Lua。

方案库的全部重置会清除 HED 设置、编队、规则和两类种子，保留 HCM 数值与方案文件。导演摘要另有仅清除原版覆盖的按钮，两种重置均需再次点击确认。

## 使用前提与兼容性

需要 Darktide Mod Loader、Darktide Mod Framework、SoloPlay，以及具备共享寻路支持的当前 Havoc Condition Manager。Realms 为可选的玩家主机联机依赖。游戏改动由本地主机执行，英文、简体中文和繁体中文随游戏语言切换。

请使用兼容的配套版本，安装后重新启动游戏。其他替换相同原版模板或调度方法的模组可能冲突。关闭 HED 后，HCM 可以独立运行。

## Vortex 安装

- 关闭游戏并安装前置。使用 Install From File 导入本 ZIP，启用后选择 Deploy Mods。
- Load Order 顺序：SoloPlay → HavocConditionManager → HavocEnemyDirector。
- 重新启动游戏，从模组选项打开 Havoc Enemy Director。

## 手动安装

- 关闭游戏。升级时先移除旧 HavocEnemyDirector 安装文件夹，再解压新包；设置与方案存放在其他位置。
- 解压到 Darktide/mods，得到 mods/HavocEnemyDirector。
- 在 mods/mod_load_order.txt 中将 HavocEnemyDirector 排在 HavocConditionManager 后，SoloPlay 位于两者之前。
- 重新启动游戏，从模组选项打开 Havoc Enemy Director。
